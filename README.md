# Мои финансы

Личный трекер доходов и расходов в гривнах и долларах. Работает как сайт и устанавливается на домашний экран iPhone.

- Главная: общий баланс, баланс в гривнах и в долларах
- Статистика: итоги, график по месяцам, категории
- Записи: доходы, расходы и обмен валюты, отдельно для ₴ и $
- Настройки: начальный баланс, курс доллара, копия данных

Данные хранятся только на устройстве. Время от времени скачивайте копию в настройках.
